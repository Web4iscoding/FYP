# 粵語小聲音 · Final Year Project

A React Native demo of **“A mobile application for children to conduct preliminary assessments of their Cantonese pronunciation.”** It supports children and caregivers through listening, local recording, clearly simulated preliminary results, and repeatable pronunciation practice. It is not a clinical assessment.

The app is in [`mobile/`](mobile/README.md); the existing research dataset and collection scripts remain separate and unchanged.

```sh
cd mobile
npm install
npx expo start
```

Use a current Node 22 LTS release. Press `a` for Android, `i` for iOS, or scan the QR code using a compatible Expo Go app on a physical phone. See the [mobile setup and demo guide](mobile/README.md) for prerequisites, browser preview, testing, and future Flask/Qwen integration.
